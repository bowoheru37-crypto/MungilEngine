01 · Brief proyek

Satu brief menjadi konteks bersama semua task agent.

“Tanpa bugs” atau kualitas sempurna tidak bisa dijamin. AI perlu model/backend, credentials aman, tools berizin, build + test nyata, dan persetujuan manusia. Mode default di sini lokal tanpa pengiriman brief.

02 · AI provider (opsional)

Adapter endpoint opsional. Tanpa backend yang compatible, gunakan skill lokal. Jangan masukkan API key di URL/browser; endpoint server milikmu yang mengurus autentikasi dan provider.

Kontrak POST JSON: {agentId,role,skill,brief,projectId}. Respon JSON: {output:"..."} atau {choices:[{message:{content:"..."}}]}. Client tidak mengirim header auth.
