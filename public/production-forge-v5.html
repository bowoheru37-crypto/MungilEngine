02 · AI endpoint opsional

Hubungkan backend provider-compatible milikmu. Client tidak menerima/menyimpan API key; endpoint harus mengelola secret secara server-side.

POST JSON: {agentId,role,skill,task,brief,projectId}. Response: {output:"..."}, {text:"..."}, atau {choices:[{message:{content:"..."}}]}. Client tidak mengirim auth header. Endpoint harus HTTPS, CORS, rate-limit, timeout, privacy policy.

05 · Android / Itel A70 release readiness

Checklist rencana, bukan APK yang telah dibuild.

  • Periksa proyek Android wrapper (mis. Capacitor) dan versi Android Gradle Plugin/SDK yang kompatibel.
  • Pin toolchain; jalankan lint, tests, production build, Android assemble dan artifact verification di CI.
  • Ukur cold start, frame-time, memory, thermal, input latency dan offline behavior pada Itel A70 fisik.
  • Signing/release keys hanya di secret store CI, jangan commit ke repository atau browser.
  • Audit permissions, privacy/data flow, asset licenses, SBOM, rollback dan store declarations.
Repository yang diperiksa adalah Vite/PWA; tidak ditemukan Android Gradle/Capacitor release project pada tree inspeksi. Belum ada APK release yang dapat saya klaim/build.
